# Journey verification procedure

Reconstructed tutorial fixture. Newly authored for QORE-003; not an authentic historical protocol or evidence of a website defect.

1. Open the public Labs entry and follow its journey link.
2. Start the check without selecting an answer.
3. Open help using its summary control.
4. Reach Close with Tab or Shift+Tab, activate with Enter, and assert that help is closed and the summary is focused.
5. Assert that the first question remains unanswered.
6. Click Back, then assert that the introduction is visible, the question and help are absent, and the introduction heading is focused.
