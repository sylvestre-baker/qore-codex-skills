# Technical demonstration

[Watch the 78-second technical demo](technical-demo.mp4). It is silent H.264 at 1280 × 800, with an embedded default English subtitle track, [WebVTT captions](technical-demo.en.vtt) and [transcript](transcript.md).

The video presents actual planning, review, browser and focused profile evidence from separate runs. Authored scene cards and report excerpts are visibly different from the genuine browser footage. Source times and candidate identities remain explicit; the presentation is thematic rather than a single chronological session.

The concrete validator example has [self-contained before/after command receipts](verifier-flag-probe.json), [the explicit empty packet](evidence/empty-findings.json) and both identified helper snapshots. The old candidate accepted one malformed token; the current helper snapshot rejected that same token. This narrow replay does not prove exhaustive grammar correctness or actual independent verifier execution.

[Provenance](provenance.json) maps the presentation to original source digests and transformations. The video makes no general gain, superiority, full-site quality, external human first-use or admission claim. It is a technical artifact, not a personal application video.
