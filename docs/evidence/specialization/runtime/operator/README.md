They are not new supported product commands, an installer or a general agent scheduler.

Only declared private campaign, repository, authentication-file and installed-driver paths are replaced with placeholders. No credential content is included. The original freeze hashes identify unchanged raw operator source before path redaction; the public derivatives have separate digests. The normalization helper evolved to recognize actual retained roster layouts and accounting fields; it never changes task inputs or worker phase conclusions. Actual launch, boundary, output, phase and cell records remain the execution evidence.

The outer process timeout and eventual owned-container cleanup are observable controls, not proof of immediate descendant cancellation. Exact child compute and billing are unavailable. The upstream seccomp profile and dependencies are not bundled here. The locally available image and the qualified permission behavior must be re-established before any independent reuse. Full package qualification, controlled reduced-input trials and external human first use remain distinct.
