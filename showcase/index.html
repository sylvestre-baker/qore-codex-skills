python3 tools/qore.py derive \
  --profile profiles/qaizen-labs.json \
  --project-root examples/qaizen-labs \
  --output /tmp/qore-labs-new
python3 tools/qore.py verify /tmp/qore-labs-new

Run from a checkout of this candidate, using an unused output path. Python 3 is required. The assembler validates data; it does not execute profile commands or grant permission.

Inspect before trusting

Problem → execution → evidence → decision

The supported decision is to use separate keyboard reachability, resolved-state and focus checks for this declared flow, and to preserve criteria-bound independent review in the optional coordination workflow. This does not establish a general quality or speed advantage.

Where this evidence stops

Browser observations cover one dated desktop English entry/state flow. They do not certify accessibility conformance, performance, every question, native apps or future deployments. Linux qualification ran without a browser driver; browser tests skipped there are not passes.

Agent Mail is optional. Separate sessions communicate through actual messages, while an operator starts or resumes bounded work turns. There is no automatic wakeup claim. Cooperative session identity is not cryptographic isolation. The persistent dependency recommendation remains partial.

No external human first-use trial was observed. No Ambassador admission, endorsement or comparative improvement is claimed. Private website source, raw mail logs, credentials and raw browser traces are excluded.

Use the method your task needs

Qore is for developers already using Codex. These skills are independent; ordinary small changes may only need repository instructions or a direct check. Use your host’s routine code-review workflow for ordinary Git diff review.
